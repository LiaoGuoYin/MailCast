管理密码

密码由 Cloudflare 管理。修改或忘记密码时，前往 Worker → Settings → Variables and Secrets，更新 ADMIN_PASSWORD（Secret）并部署。新密码生效后，所有设备需要重新登录（已签发的 Agent Token 保持有效，可在下方随时吊销）。

邮件发送

默认通过 Resend 重新发送到任意邮箱；也可切换到 Cloudflare Email Sending。

API Key 将保存在 D1 中，保存后不会回显。
MCP · AGENT

Agent 接入（MCP）

通过无状态 Streamable HTTP（POST /mcp）向 Claude Code、Codex 等客户端开放受控收信、等验证码与发信能力。每个 Token 独立限制前缀、收件人白名单与发信频控。

0 个有效 Token
Agent 发信与自动转发共享发信额度（Resend 免费档约 100 封/天），填 0 表示全局禁止 Agent 发信。

AI 摘要与验证码识别

启用后，Telegram 与 Bark 推送会先由模型提取验证码并生成精简摘要；未启用或调用失败时，自动清洗 HTML/CSS 并推送正文摘录，不影响投递。
